# 开发脚本

遵循[仓库规则](../AGENTS.md)。脚本负责机械检查、改动盘点和本地安装，不代替审阅判断。

- 将可重复的仓库操作接入 [Makefile](../Makefile)；验证顺序和执行结果由 `harness.py` 维护。
- 默认只读。安装预览与实际写入分开；不覆盖已有来源，不自动提交、推送或修改个人配置。
- 子进程使用参数数组，限制运行时间与输出；失败或中断时停止并清理自己启动的进程。
- 新增检查以隔离的正常和错误样例验证，错误须返回非零状态并指出原因。不要修改真实仓库制造失败，不读取真实账号或会话作为测试材料。
- 源文件检查不依赖构建产物。本地安装只分发公开技能，项目工作流留在仓库中；保留许可证、资源和来源入口。
