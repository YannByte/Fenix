# Fenix

**火凤凰 · Yann 的开源 AI Agent Skill 库。**

把日常工作中可复用的方法整理成 Skill，逐步积累、验证和改进。

当前仓库已初始化基础结构，首批 Skill 尚未收录。技能清单见 [skills](skills/README.md)。

## 目录结构

```text
Fenix/
├── README.md
├── AGENTS.md
├── CONTRIBUTING.md
├── LICENSE
└── skills/
    └── README.md
```

每个 Skill 使用独立目录，以 `SKILL.md` 说明用途、触发条件和执行步骤；需要时附带脚本、参考资料或模板。

## 获取仓库

```sh
git clone https://github.com/YannByte/Fenix.git
```

具体使用方式由每个 Skill 自己说明。添加或改进 Skill 前，请阅读[贡献指南](CONTRIBUTING.md)。
