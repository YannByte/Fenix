# 数据展示

用于仪表盘、分析页面、图表和密集数字界面。先明确用户要回答的问题，再选择摘要、筛选、图表与明细，不套营销页面结构。

## 信息与布局

主要结论或状态应能直接找到，补充记录按需展开。核对少量、典型和空数据，不用填充内容掩盖布局问题。

同列数字保持一致格式与对齐，可用 `font-variant-numeric: tabular-nums`；标签与单位清楚，列间距区分信息组。分隔线、行底色和密度按实际扫描任务决定，不强制固定列数、间距或透明度。

## 图表选择

| 问题 | 可选表达 |
| --- | --- |
| 类别间比较 | 条形图；长标签可用横向布局 |
| 随时间变化 | 折线图；按采样与数据语义选择间隔 |
| 整体与部分 | 堆叠条形图、矩形树图或少量部分的饼图；类别较多时比较可读性 |
| 分布 | 直方图、箱线图或合适的分布表达 |
| 变量关系 | 散点图；不要让连线暗示不存在的顺序或因果 |

说明时间范围、单位、基线、缺失值与聚合方式，不让截断坐标、颜色或面积夸大差异。交互筛选与静态图应使用一致的统计口径。

## 参考与验证

按[UI 方向](design-ui.md)提取参考产品中的具体属性，例如配色、网格线、轴标签、提示框与空状态。已有产品令牌优先，不只复述“干净、专业”。

核对数值与图形映射、长标签、极值、空结果、筛选后状态及真实渲染。模拟数据明确标注，不把样例指标当作业务事实。
