# 局部视觉修正

用于既有界面的溢出、裁切、换行、对齐、间距、对比和响应问题。先读实际渲染与负责组件，确定具体缺陷及本次允许改变的范围。

沿用[截图迭代](mode-screenshot-iteration.md)中的目标、保留边界和证据判断。做最小有效修改，再检查真实结果；发现新的产品取舍或范围扩大时补充确认，不按文件数或组件数自动升级流程。

- 共享组件或令牌改变时核对相关使用位置；按实际影响检查长文本、本地化、紧凑布局和状态切换。
- 间距反复调整无效时先查父容器、约束与尺度，不仅凭尝试次数就判定必须重构。
- 固定操作区域交换内容时保持几何和文字层级稳定；确实需要不同字号时验证状态切换，不强制所有状态使用同一字号。
- 加载、测量、索引或权限等待不能显示最终空结果。刷新时保留旧结果并标明状态，或显示明确进度。
- 清理、删除和重置界面要让用户能确认对象、范围和恢复后果；减少点击不应隐去必要信息。按实际风险决定预览与确认方式。
- 优先修复误导的状态与空操作入口，不为显得丰富增加控件。完成界面先呈现用户需要的结果，附加详情按需展开。

CLI 文字或排版改变时运行实际命令检查输出。UI 检查真实渲染；无法执行时说明具体缺口，不用构建通过代替视觉验证。
