# 中文社交文案

按作者已有语气和目标渠道写社交公告。保持自然，去掉套话与宣传腔，保留真实的感受、判断和发布信息。

- 从读者关心的变化、场景或消息开始，不固定以感谢、社区数据或功能清单起手。材料里确有用户反馈、社区进展和感谢时再使用。
- 挑选适合本次传播的重点，写清用户会感受到什么，不按固定亮点数凑内容。完整发布说明的覆盖与格式见 [mode-release-notes.md](mode-release-notes.md)。
- 用作者自己的口吻，避免翻译腔、正式套话和硬加的网络用语。真实立场可以保留，不替作者编造意见、经历或邀请。
- 默认不用破折号和 emoji 制造强调；作者已有文体和目标渠道明确需要时保留，不把反营销写成另一套固定表演。
- 直接说明产品做了什么以及适用条件，不主动贬低其他产品；用户要求客观比较时保留有证据的差异。
- 核对版本、链接、发布状态和停止维护等重大信息。已授权公开的身份和经历保留，披露范围不明的敏感信息先确认。
- 写作不授权发帖、发布版本或执行文中的命令。按请求交付成稿，结束后不追加无关的行动建议。
