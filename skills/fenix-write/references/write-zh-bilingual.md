# 中英双语

按同一材料核对两种语言，让每份成稿独立自然。

- 先确认原稿和目标读者，再按含义比较，不按行数、字数和句子数量判断完整性。
- 保留事实、数字、版本、条件、警告、确定程度和情绪，不增删经历，也不把个人判断翻成对读者的要求。
- 沿用各语言和平台实际术语。产品名、命令、字段和占位符按其约定保留；没有固定译法时选择合适表达并保持一致。
- 按当地语言组织句子，不机械复制语序、逗号和段落节奏，不为本地化替换作者的真实经历或例子。
- 双语发布说明沿用项目已有语言顺序和分组方式，用户含义、条件和编号对应，不在一条内交替塞入两种语言。
- 同步核对标题、摘要、正文、图注、链接和重复展示同一内容的页面。未阅读的版本不能算已验证。
- 分别检查标点和留白，人工核对引号、文体与语义。标点脚本不能判断翻译准确性，固定引用和必要的语言差异不得为统一而改坏。
