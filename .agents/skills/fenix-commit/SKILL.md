# Fenix 提交

先运行 `make scope PYTHON=.venv/bin/python`，核对[仓库规则](../../../AGENTS.md)与[提交流程](../../../docs/development.md#审阅与提交)。按目的分组，保留无关修改和用户原有的部分暂存。

复用覆盖当前差异的审阅结论；未覆盖的部分使用 [fenix-review](../fenix-review/SKILL.md)，检查由 [fenix-verify](../fenix-verify/SKILL.md)选择。失败或未解决的问题阻止受影响的提交，不将静态通过写成完整行为验收。

只暂存本次任务的具体路径。暂存后检查完整差异、敏感信息和遗漏资源；提交前重新读取 HEAD 和工作区。出现任务外改动或 HEAD 意外变化时停止，不自动重置、藏起修改或改写历史。

用户要求提交时可执行提交，无须重复确认；推送、创建 Tag 和远端发布只按当前任务已有授权执行。推送前再核对分支、远端与 HEAD，普通推送后读取远端提交和 CI。报告提交编号、验证结果及剩余改动，不自动升级版本或创建发布记录。
