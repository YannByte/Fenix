# Fenix 本地安装

读取[本地安装约定](../../../docs/development.md#本地安装)，先运行 `make install-plan PYTHON=.venv/bin/python`。预览只检查来源和目标，不写入个人目录；有冲突时说明具体路径，不删除、覆盖或接管其他来源。

用户已授权本地安装后执行 `make install-local PYTHON=.venv/bin/python`；只要求预览或检查时保持只读。自定义目标目录使用流程中记录的入口。源文件有改动时先完成适用验证；安装成功不能代替任务效果或宿主加载验证。

安装后核对每个链接、`SKILL.md`、资源与许可证仍可达，报告新增、原样保留和冲突项。链接依赖仓库位置，后续源码修改直接生效；下次对话轮次可发现技能，不声称当前会话已重新加载。中途失败只回收本次创建的链接，保留已有内容；不自动提交或推送。
