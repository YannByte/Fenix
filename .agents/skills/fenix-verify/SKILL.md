# Fenix 改动验证

按[开发流程](../../../docs/development.md#验证)选择范围，通过 `make verify SCOPE=<repository|full> PYTHON=.venv/bin/python` 执行。入口定位自身仓库，遇到失败停止并列出已完成阶段；失败阶段和后续阶段不能算通过。

先检查实际差异和已有验证证据，复用输入未变化的通过结果；修改失败路径或输入后重跑受影响检查。区分依赖缺失、运行环境限制和断言失败，定位同类问题后统一修复，不盲目重复完整测试。

技能效果、外部提取服务和宿主加载不由静态校验证明。任务改变技能行为时，按实际场景补验证；安装变更使用隔离目录验证，不向真实个人目录写入测试材料。只报告本次实际运行，或明确标记复用的提交、范围和条件。
